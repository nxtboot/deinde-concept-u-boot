Logos
=====

Deinde Concept
--------------

This tree uses the Deinde Concept Tree logo, which appears on the boot
display and at the top of this documentation.

.. image:: ../../tools/logos/deinde-concept-tree.svg
  :width: 10em
  :alt: Deinde Concept Tree logo

The boot display uses ``drivers/video/images/deinde.bmp``, generated from
the same artwork, which is also kept beside it as
``drivers/video/images/deinde-concept-tree.svg``.
